
# SaaS Revenue Intelligence Platform

An end-to-end, AI-powered SaaS Revenue Intelligence Platform built to analyse subscription revenue, customer retention, product usage, invoicing and payment performance.

## Project Objectives

- Build an end-to-end data engineering pipeline.
- Implement Bronze, Silver and Gold data layers.
- Calculate MRR, ARR, churn, NRR and revenue growth.
- Implement incremental data processing.
- Build data quality and reconciliation checks.
- Develop an interactive revenue analytics dashboard.
- Integrate an AI-powered natural language analytics assistant.

## Technology Stack

- Python
- SQL
- Google BigQuery Sandbox
- Dataform (subject to free-tier compatibility)
- Streamlit
- Plotly
- Git and GitHub
